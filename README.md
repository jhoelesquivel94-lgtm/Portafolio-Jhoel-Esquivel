# Portafolio — Jhoel Esquivel

Sitio estático (HTML, CSS y JavaScript sin build) publicado en Vercel.

- `index.html` — estructura
- `styles.css` — estilos
- `motion.css` — estilos de las animaciones
- `motion.js` — contenido (proyectos, certificados, trayectoria) y animaciones con GSAP + ScrollTrigger y scroll suave con Lenis
- `dunes.js` — paisaje 3D del inicio con Three.js
- `vendor/` — Three.js, GSAP y Lenis incluidos (sin depender de CDN)

Para agregar un proyecto, edita el arreglo `projects` en `motion.js` y pon sus capturas en `img/`.
