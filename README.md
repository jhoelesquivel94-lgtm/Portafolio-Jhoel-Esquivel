# Portafolio — Jhoel Esquivel

Sitio estático (HTML, CSS y JavaScript sin build) publicado en Vercel.

- `index.html` — estructura
- `styles.css` — estilos
- `script.js` — contenido (proyectos, certificados, trayectoria) e interacción
- `dunes.js` — paisaje 3D del inicio con Three.js (`vendor/three.module.min.js`, licencia MIT)

Para agregar un proyecto al carrusel, edita el arreglo `projects` en `script.js` y pon sus capturas en `img/`.
